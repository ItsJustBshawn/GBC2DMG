# Changelog

## 0.4-beta.2

- Python download with no third-party packages required.
- Simple GUI: choose a ROM, convert it, or save a version report.
- Windows launcher and `.pyw` entry point.
- Documentation explaining the port and support for other games.

The converted Crystal ROMs are unchanged from beta 1.

## 0.4-beta.1

First public beta: English Crystal 1.0 and 1.1, automatic version detection and local conversion.
