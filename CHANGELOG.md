# Changes

## 0.4-beta.1

- Name the application GBC2DMG.
- Support English Crystal 1.0 and 1.1 as exact, approved beta inputs.
- Recognize Rev A and Rev 1 as aliases for 1.1.
- Add ROM identification, checksum details and copy/save version reports.
- Preserve each revision in its converted output.
- Include the current DMG graphics fixes and in-play clock.
- Package a portable Windows app, checksums and a local scan report.
